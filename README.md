# czechowski.tech

Personal engineering portfolio for Piotr Czechowski — Full Stack AI Engineer working at the seam of computer vision, embedded systems, and live video.

## Stack

- Next.js (App Router, TypeScript)
- Motion for React (`motion/react`)
- `next/font` (`Instrument Sans`, `IBM Plex Mono`, Latin & Polish diacritics)
- Playwright smoke tests

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npx tsc --noEmit
npm run build
npm run test:e2e
```
